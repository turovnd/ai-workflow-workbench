# API

[Swagger UI](https://turovnd-support-desk.vercel.app/docs/) · [OpenAPI schema](https://turovnd-support-desk.vercel.app/openapi.json)

Start with `POST /auth/demo`, or register/sign in, then use the returned opaque token as `Authorization: Bearer …`. The token determines the workspace; the API never accepts a client-selected workspace identity.

| Action                           | Endpoint                                        |
| -------------------------------- | ----------------------------------------------- |
| Read identity / sign out         | `GET /auth/me`, `POST /auth/logout`             |
| Browse requests                  | `GET /tickets?status=open&limit=12&cursor=…`    |
| Open a request                   | `GET /tickets/:id`                              |
| Prepare a reply                  | `POST /tickets/:id/runs`                        |
| Read progress / persisted events | `GET /runs/:id`, `GET /runs/:id/events?after=…` |
| Edit or approve a saved draft    | `POST /runs/:id/draft`, `POST /runs/:id/reply`  |
| Browse history                   | `GET /tickets/:id/history?limit=6&cursor=…`     |

Swagger contains the exact bodies and response schemas. Invalid input is rejected before data access. Missing or expired identity returns 401; unknown workspace-scoped resources return 404; stale versions and conflicting approvals return 409.

Pagination returns `items` and `nextCursor`. Treat cursors as opaque, preserve the filter and stop when `nextCursor` is null. Refresh starts a new traversal.

## Generated frontend client

```sh
npm run api:generate -- --url http://127.0.0.1:4010/openapi.json
npm run api:check
```

`frontend/src/api/generated.ts` is generated by swagger-typescript-api. Transport, session handling and runtime validation are separate files. The check exports the schema into a temporary directory without connecting to a database, regenerates the client and compares it. No root-level `openapi.json` snapshot is maintained.
